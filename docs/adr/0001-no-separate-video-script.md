# 0001. No separate video script document

- Status: Accepted（2026-10-28、ユーザー決定）
- Date: 2026-10-27

## Context
`docs/brief.md` は成果物に `docs/video-script.md`（場面、字幕、尺、倍速の有無）を挙げていたが、課題の提出物は動画・コード・レポートの 3 点で、台本は採点対象ではない。レポートに求められるのは概要・目的・工夫点であり、動画の場面構成はその要件に含まれない。提出動画は 2026-10-27 に YouTube へ公開済みで、場面構成を文書に残す必要はもうない。締切は 2026-11-02 10:00 で、台本を独立した文書として書き、補助の `verify` を通す時間はレポートの仕上げに回したい。

## Decision
動画の台本は独立した文書として作らず、レポート（`docs/report.md`）にも場面構成の節を置かない。動画は 2026-10-27 に公開済みで、その内容は動画自体が示す。

## Consequences
- `docs/brief.md`、`README.md`、`AGENTS.md` から `docs/video-script.md` への言及を外す（本 ADR の初版と同じコミット）
- `docs/report.md` から動画の場面構成を書いた節を削り、`docs/brief.md` の成果物の記述を「場面構成はレポートにも書かない」に合わせる（2026-10-27）
- 動画の内容とレポートの数値（4 組合せの成功、uc-13 の停止）が矛盾しないことは、レポートの `verify` で `docs/evidence/` の記録と突き合わせて確認する
